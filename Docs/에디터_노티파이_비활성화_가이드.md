# 에디터 (Prefab, Animation) 뷰 애니메이션 노티파이 비활성화 가이드

현재 `Prefab_View`와 `Animation_View`에서 모델의 애니메이션을 재생/갱신할 때 이펙트 및 사운드 등의 노티파이가 실제 게임처럼 발생하여 뷰포트 내에 재생되는 현상이 있습니다.
이를 방지하기 위해 엔진 단의 `Model` 클래스에 자체 노티파이 켜기/끄기 플래그를 두고, 에디터의 프리뷰 갱신 직전에만 꺼두는 코드를 추가합니다.

이 방식은 각 클라이언트의 객체(`Player.cpp` 등)에서 `Play_Animation(timeDelta, true)`와 같이 강제로 `true`를 넘기더라도 영향을 받지 않도록, `Model` 내부에서 AND 연산으로 한 번 더 확인하여 차단하는 안전한 방법입니다.

---

## 1. Engine/Public/Model.h 수정
모델 클래스에 노티파이 비활성화 플래그(`_bEnableNotifies`)와 접근자를 추가합니다.

### 수정 위치:
```cpp
// ... 생략 ...
public: /* 노티파이 */
    bool    Ensure_AnimNotifyAssetLoaded();
    void    Invalidate_AnimNotifyAsset();
    const FAnimNotifyClipData* Find_CurrentNotifyClip() const;

// [추가] 노티파이 재생 제어를 위한 Getter / Setter 추가
    void    Set_EnableNotifies(bool enable) { _bEnableNotifies = enable; }
    bool    Is_EnableNotifies() const { return _bEnableNotifies; }

    // 노티파이 스테이트 정리
    void    Stop_AllNotifyStates(bool executeEndCheck);
// ... 생략 ...

private: /* 노티파이 */
    bool                            _isAnimNotifyAssetLoaded = false;
    FAnimNotifyAsset                _animNotifyAsset;
    vector<FActiveAnimNotifyState>  _activeNotifyStates;

    bool                            _bEnableNotifies = true; // [추가] 기본 값은 항상 true

public:
// ... 생략 ...
```

## 3. Editor/Private/Prefab_View.cpp 수정
프리펩 뷰가 실제로 프리뷰 오브젝트를 `Update` 시킬 때, 직전에 모델의 노티파이 플래그를 저장/비활성화하고 끝난 후 복구합니다.

### 수정 위치: `Prefab_View::Pre_Render()`
```cpp
void Prefab_View::Pre_Render()
{
    // ... 생략 ...
    previewLight.specular = Vec4(0.f, 0.f, 0.f, 1.f);

    GAME->Clear_Lights();
    GAME->Add_Light(previewLight);

    float dt = ImGui::GetIO().DeltaTime;

    bool wasEnableInput = GAME->Is_GameInputEnabled();
    GAME->Set_GameInputEnabled(false);

    // [추가] 로드된 프리뷰 모델의 노티파이를 강제로 끔
    auto model = Find_PreviewModel();
    bool wasEnableNotifies = true;
    if (model)
    {
        // 원래 설정을 저장하고 끈다.
        wasEnableNotifies = model->Is_EnableNotifies();
        model->Set_EnableNotifies(false);
    }

    _previewObject->Priority_Update(dt);
    _previewObject->Update(dt);
    _previewObject->Late_Update(dt);

    // [추가] 업데이트 종료 후 원래 설정으로 복구
    if (model)
    {
        model->Set_EnableNotifies(wasEnableNotifies);
    }

    GAME->Set_GameInputEnabled(wasEnableInput);

    _prevRT->Clear(Color(0.15f, 0.15f, 0.15f, 1.f));
    _prevRT->BindAsTarget();

    GAME->Draw();
    // ...
}
```

## 4. Editor/Private/Animation_View.cpp 수정
애니메이션 뷰 역시 프리뷰 오너(현재 객체)를 `Update` 시켜 애니메이션 프레임을 갱신하므로 이 곳도 동일하게 보호합니다.

### 수정 위치: `Animation_View::Pre_Render()`
```cpp
void Animation_View::Pre_Render()
{
    // ... 생략 ...
    previewLight.ambient = Vec4(1.f, 1.f, 1.f, 1.f);
    previewLight.specular = Vec4(0.f, 0.f, 0.f, 1.f);

    GAME->Clear_Lights();
    GAME->Add_Light(previewLight);

    float dt = ImGui::GetIO().DeltaTime;

    bool wasEnableInput = GAME->Is_GameInputEnabled();
    GAME->Set_GameInputEnabled(false);

    // [추가] 애니메이션 뷰에서 타임라인 진행 시 노티파이가 실제 발동되지 않도록 제어
    bool wasEnableNotifies = true;
    if (_model)
    {
        wasEnableNotifies = _model->Is_EnableNotifies();
        _model->Set_EnableNotifies(false);
    }

    _previewOwner->Priority_Update(0.f);
    _previewOwner->Update(0.f);
    _previewOwner->Late_Update(0.f);

    // [추가] 업데이트 후 원복
    if (_model)
    {
        _model->Set_EnableNotifies(wasEnableNotifies);
    }

    GAME->Set_GameInputEnabled(wasEnableInput);

    _previewRT->Clear(Color(0.12f, 0.12f, 0.12f, 1.f));
    _previewRT->BindAsTarget();

    GAME->Draw();

    GAME->BindBackBuffer();
    // ...
}
```

## 완료 후 빌드

위의 4개 파일 수정을 완료한 후 `Engine`과 `Editor`를 다시 빌드(`Ctrl + Shift + B`)해 줍니다. 
1. 에디터를 열고 프리팹 뷰에서 캐릭터를 띄웁니다.
2. 애니메이션을 재생 시켜 사운드나 이펙트가 무분별하게 터지는지 확인합니다. 발생하지 않았다면 성공입니다!
