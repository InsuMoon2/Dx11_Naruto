## 무기는 평소 등 뒤, 공격 중에만 손으로 붙이는 구조

### 요약
- `무기 타입`과 `부착 위치`를 분리한다.
- `EWeaponType`는 공격 프로필/애니메이션 선택용으로 유지하고, 소켓 부착은 별도 규칙으로 관리한다.
- 기본 규칙은 단순하게 간다.
  - 평소: `Attach_Sword`
  - 공격 상태: `R_Hand_Weapon_cnt_tr`
  - 공격 종료 후: 다시 `Attach_Sword`
- 런타임은 상태 기반 자동 전환, 프리뷰는 수동 override를 둔다.

### 핵심 변경
- [Player.h](/d:/GitDesktop/Dx11_Naruto/Client/Public/Player.h), [Player.cpp](/d:/GitDesktop/Dx11_Naruto/Client/Private/Player.cpp)
  - `Find_WeaponSocketMatrix(EWeaponType)`를 `Find_WeaponSocketMatrix(EWeaponAttachPose)`로 분리
  - `EWeaponAttachPose`는 `Back`, `Hand`
  - `Change_WeaponAttachment(EWeaponAttachPose pose)` 추가
  - `Resolve_AttachPoseForState(EPlayerState state)` 추가
  - 규칙:
    - 현재 무기 타입이 `Hand`면 어떤 상태여도 `Back`
    - 현재 무기 타입이 `BigSwrod`이고 상태가 `Attack`, `JumpAttack`면 `Hand`
    - 그 외는 `Back`
  - 소켓 이름은 고정:
    - `Back` -> `Attach_Sword`
    - `Hand` -> `R_Hand_Weapon_cnt_tr`
    - fallback -> `RightHand`, 마지막 fallback -> `Attach_Sword`
- [PlayerStateMachine.cpp](/d:/GitDesktop/Dx11_Naruto/Client/Private/PlayerStateMachine.cpp)
  - `Change_State(EPlayerState newState)`에서 상태 전환 직후, 새 상태 `Enter()` 전에 플레이어의 무기 부착 위치를 갱신
  - 이유: 공격 애니메이션 시작 프레임부터 손에 있어야 어색하지 않음
  - 중앙 규칙으로 처리해서 `PlayerState_Attack`, `PlayerState_JumpAttack`에 중복 코드 넣지 않음
- [Prefab_View.cpp](/d:/GitDesktop/Dx11_Naruto/Editor/Private/Prefab_View.cpp)
  - 프리뷰 애니메이션은 raw clip 재생이라 상태머신을 안 타므로 자동 전환이 안 됨
  - `Draw_AnimationControls()`에 `Weapon Attach Preview` UI 추가
  - 값:
    - `Back`
    - `Hand`
  - `Apply Preview Animation` 직후 프리뷰 대상이 `Player`면 선택된 pose로 `Change_WeaponAttachment(...)` 호출
  - 별도 `Reattach Weapon` 버튼도 추가해서 애니메이션은 그대로 두고 소켓만 다시 맞출 수 있게 함

### 동작 규칙
- 런타임:
  - `Idle`, `Run`, `Jump`, `Dash`, `Land`, `Skill` 등은 기본 `Back`
  - `Attack`, `JumpAttack`만 `Hand`
  - 공격 종료 후 다음 상태가 되면 자동으로 다시 `Back`
- 프리뷰:
  - 자동 추론 없음
  - 사용자가 `Back/Hand`를 직접 고른다
  - raw clip 미리보기에서도 위치 잡기가 쉬워진다

### 테스트
- `BigSwrod` 상태에서 `Idle/Run`은 무기가 등에 있어야 한다.
- `BigSwrod` 상태에서 `Attack` 진입 즉시 무기가 손 소켓으로 와야 한다.
- `JumpAttack`도 손 소켓으로 와야 한다.
- 공격 종료 후 `Idle/Run` 복귀 시 다시 등에 가야 한다.
- `Hand` 상태에서는 `Attack`이어도 계속 등에 있어야 한다.
- 프리뷰에서 `Back/Hand`를 바꾸고 `Apply Preview Animation` 또는 `Reattach Weapon`을 누르면 즉시 위치가 바뀌어야 한다.

### 가정 및 기본값
- 1차 범위는 `Attack`, `JumpAttack`만 손 부착 상태로 본다.
- `Skill`은 일단 전부 `Back`으로 둔다.
- 나중에 필요하면 `SkillData`에 `requiresWeaponInHand` 같은 플래그를 추가해 확장한다.
- 전환 타이밍은 노티파이보다 먼저, 상태 전환 시점으로 고정한다.
