# 벽 점프 연속 부착 문제 해결 가이드라인

## 1. 현재 문제 현상 및 원인 분석

벽(Wall Run) 상태에서 점프를 할 때, 특히 대각선 입력을 한 채로 점프하면 **"점프하자마자 다시 벽에 딱 붙어버리는 현상"**이 발생합니다. 그 원인은 다음과 같습니다.

1. **에어 컨트롤(Air Control)의 즉각형성**: `Start_WallJump()`에서 벽의 법선 벡터 반대 방향으로 `_velocity`를 세팅해 튕겨내지만, `Update_Velocity()`에서 즉시 대각선 사용자 입력(`desiredDir`)을 받아 다시 벽 쪽으로 이동 모멘텀을 생성합니다.
2. **벽타기 조건의 즉시 충족**: `Apply_Movement`에서 쿨타임 체크(`_wallJumpCooldown`)가 주석 처리되어 있어, 방향만 벽 쪽(`intoWall > 0.15f`)을 향하면 `Can_EnterWallRun`이 즉시 `true`가 되어 다시 부착됩니다.
3. **벽 관통 구조적 문제**: 쿨타임을 주더라도 진입(Attach)을 막을 뿐입니다. `MovementComponent` 안에 범용적인 "벽에 비비적거리기(Sliding)" 충돌 처리가 없다 보니, 쿨타임 중에 벽 쪽으로 입력을 넣으면 그대로 공중 속도가 적용되어 벽을 뚫어버리는 문제가 있습니다.

---

## 2. 제시하신 해결책들에 대한 판단

### 해결책 1번 검토: 대각선 방향 입력 시 법선 벡터로 밀어내기 (입력 저항/튕겨내기)
* **아이디어**: 대각선 입력 시 벽 법선 벡터 방향으로 강제로 점프를 밀어내서 "벽 쪽으로 점프 혹은 진입 자체를 무력화"하는 방식입니다.
* **판단 결과**: 매우 훌륭한 관점입니다. 점프 직후의 모멘텀을 물리적으로 살려주어 즉시 벽으로 붙는 현상을 자연스럽게 방지합니다. 
* **한계수치**: 이것만 적용했을 때 사용자가 점프 후 집요하게 벽 쪽으로 이동 버튼을 유지할 경우, 결국 벽에 닿게 되지만 부착은 안 되면서 `Add_WorldOffset`에 의해 위치가 벽 안쪽으로 파고드는 "관통(Clipping) 문제"가 여전히 남게 됩니다.

### 해결책 2번 검토: 벽타기 쿨타임 부여 + 벽 관통 방어
* **아이디어**: 벽 점프 직후 쿨타임을 부여해 재부착 단계를 1차적으로 강제 블록합니다.
* **판단 결과**: FSM 및 컴포넌트 관점에서 상태 전이를 제어하는 가장 직관적이고 정석적인 접근입니다. 
* **숙제**: 말씀하신 대로 쿨타임 중에는 무방비로 벽을 뚫기 때문에 이를 방지할 "벽 미끄러짐(Sliding) 보정 로직"이 반드시 뼈대로 잡혀 있어야 이 해결책이 완성됩니다.

## 3. 권장 가이드라인: 두 방식의 하이브리드 결합

결론적으로, **두 가지 방법을 융합하여 쿨타임을 살리고, 벽 투영(Projection)을 활용한 범용적인 밀어내기/슬라이딩 기능**을 추가하는 방식을 제안합니다.

### STEP A. 쿨타임의 부활 (접근법 2 반영)
`MovementComponent::Apply_Movement` 에서 주석 처리된 `_wallJumpCooldown <= 0.f` 로직을 다시 살려 재부착을 무조건 1차 차단합니다. 

### STEP B. 공중 상태에서의 벽 관통 방지 및 슬라이딩 구현 (필수)
벽타기를 못 하는 쿨타임 중에 벽을 뚫는 문제를 해결하려면, 공중에 있을 때 벽에 닿으면 남은 이동 벡터를 벽의 법선(Normal) 평면으로 투영시켜 미끄러트리는 범용 충돌 보정을 추가해야 합니다.

* `Apply_Movement` 메서드 하단(일반 공중 이동 적용 시점)에 다음과 같은 로직을 구상합니다.
1. 현재 `_velocity` 나 이동 방향 앞으로 `Detect_WallSurface`를 한 번 더 체크합니다.
2. 벽과 거리가 가깝고(닿을락 말락 혹은 파고들었다면), 벽타기가 불가한 상태(쿨타임)일 때,
3. 사용자의 이동 방향을 벽 평면을 타고 흐르도록 미끄러트립니다.
   `_velocity = Utils::Project_OnPlane(_velocity, hitNormal);`
4. 이미 파고든 위치 오차가 있다면 표면 법선 바깥쪽으로 위치(Position)를 밀어냅니다. (기존 `Apply_WallRunPosition`의 보정치 로직과 동일 원리)

이렇게 되면 벽타기 쿨타임 중에는 캐릭터가 벽을 **뚫지 않고 벽면을 타고 주욱 미끄러져 떨어지는** 자연스러운 처리가 완성됩니다.

### STEP C. 점프 초기 에어 컨트롤 잠금 (접근법 1 융합)
단순한 쿨타임만 두었을 때 점프하자마자 입력 때문에 슬라이딩 상태로 구질구질하게 벽을 돌면서 긁는 느낌이 날 수 있습니다. 이 때 1번 접근법 철학을 섞습니다.
* `Start_WallJump()`가 호출되었을 때, 아주 짧은 시간(예: `0.15`초) 동안은 `Update_Velocity`에서 `_commandDesc.moveAxis` 방면의 사용자 입력을 묵살시켜버립니다. 
* 즉, `targetVelocity = 저항값` 이 되도록 하거나 강제로 예전 반발 모멘텀을 유지합니다.
이렇게 하면 캐릭터는 사용자가 벽 쪽 스틱을 밀어도 점프 직후 시원하게 강제로 바깥쪽 궤적을 그리게 되며 액션성이 훨씬 커집니다.

## 4. 요약 및 구현 예시 (액션 플랜)

위의 권장 방식 달성을 위한 구체적인 파일별 수정 가이드라인과 코드 예시는 다음과 같습니다. (논의하신 대로 사용자의 입력을 강제 차단하지 않고, Launch + 범용 슬라이딩 보정에만 의존하여 자연스러움을 살립니다.)

### [변경] 1. MovementComponent.cpp 내 Update_Velocity 및 Start_WallJump

`Start_WallJump`에서 부여한 `launchVelocity`가 유지되도록, 쿨타임만 적용하고 여타 제약(에어컨트롤 락 등)은 두지 않습니다.

```cpp
void MovementComponent::Start_WallJump()
{
    if (!_isWallRunning)
        return;

    // 벽 바깥 방향과 위 방향을 팍 실어주어 Launch 모멘텀을 형성
    Vec3 launchVelocity = _currentWallNormal * _moveDesc.wallJumpOutVelocity;
    launchVelocity += Vec3::Up * _moveDesc.wallJumpUpVelocity;

    _velocity = launchVelocity;
    _onGround = false;
    _canDoubleJump = true;

    Exit_WallRun();

    // 벽에서 튕겨나간 직후 다시 바로 붙지 못하도록 쿨타임만 부여
    _wallJumpCooldown = 0.35f;
}
```

(기존 `Update()`나 `Update_Velocity()` 로직은 타이머/입력제한 변수 추가 없이 기존 상태 그대로 순수히 놔두셔도 무방합니다. 쿨타임 감소(`_wallJumpCooldown -= timeDelta;`) 로직 정도만 추가되어 있으면 됩니다.)

### [추가/변경] 2. Apply_Movement 쿨타임 및 벽 관통 방어 (Sliding) 처리

요청하신 "입력을 무시하진 않되, 벽 뚫기는 막는" 가장 핵심적인 보정 로직입니다. 

```cpp
void MovementComponent::Apply_Movement(float timeDelta, Shared<Transform> transform)
{
    // ... 위쪽 _isWallRunning, 지면(_velocity.y <= 0.f) 처리 유지
    _onGround = false;

    Vec3 desiredDir = Build_DesiredMoveDirection();
    FSurfaceHit wallHit{};

    // [변경점] 주석 처리되어 있던 _wallJumpCooldown <= 0.f 조건을 다시 살립니다.
    if (_wallJumpCooldown <= 0.f &&  // 쿨타임 검사 복구
        (Detect_WallSurface(transform->Get_WorldPosition(), desiredDir, wallHit) &&
        Can_EnterWallRun(wallHit, desiredDir)))
    {
        Enter_WallRun(wallHit);
        Apply_WallRunPosition(transform, wallHit);
        return;  // 벽에 다시 붙었다면 더 이상 아래 슬라이딩 관통 체크를 하지 않도록 종료합니다.
    }

    // [핵심 추가] 공중이고 벽타기 상태가 아닐 때(예: 점프 직후 쿨타임 중), 벽에 닿으면 관통하지 않고 부드럽게 미끄러지기 처리
    if (!_onGround && !_isWallRunning)
    {
        FSurfaceHit slideHit{};
        
        // 현재 위치에서 날아가려는 궤도(_velocity)를 향해 레이를 쏴 벽이 있는지 체크
        if (Detect_WallSurface(transform->Get_WorldPosition(), _velocity, slideHit))
        {
            Vec3 moveDir = _velocity;
            moveDir.Normalize();

            // 나의 이동 방향이 정확히 벽을 파고드는 방향일 때만 슬라이드 처리 작동
            if (moveDir.Dot(slideHit.hitNormal) < 0.f)
            {
                // 1. Project_OnPlane을 통해 벽을 파고드는 힘은 모두 지우고 파장(평면) 방향으로만 미끄러지게 보정
                _velocity = Utils::Project_OnPlane(_velocity, slideHit.hitNormal);

                // 2. 만약 Transform이 이미 벽 안쪽으로 미세하게 들어갔다면 외곽으로 살짝 밀어내기 보정
                Vec3 currentPos = transform->Get_WorldPosition();
                float dist = (currentPos - slideHit.hitPoint).Dot(slideHit.hitNormal);
                
                if (dist < _moveDesc.wallAttachOffset) 
                {
                    currentPos += slideHit.hitNormal * (_moveDesc.wallAttachOffset - dist);
                    transform->Set_WorldPosition(currentPos);
                }
            }
        }
    }
}
```
