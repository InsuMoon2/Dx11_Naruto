## 1. 프로젝트 한 줄 요약

`Dx11_Naruto`는 DirectX 11 기반 게임 엔진, 게임 클라이언트 DLL, 실행 EXE, ImGui 에디터, IOCP 서버, Assimp 변환 도구, 리소스 데이터 파이프라인이 함께 들어 있는 C++ 게임 프로젝트다.

핵심 흐름은 아래처럼 본다.

```text
Engine  -> 공용 엔진 DLL
Client  -> 게임 로직 DLL
Game    -> 실제 실행 EXE
Editor  -> ImGui 기반 개발/편집 EXE
Server  -> ServerCore + GameServer
AssimpTool -> FBX/OBJ 변환 도구
Resources -> JSON, 모델, 이펙트, 사운드, 셰이더, 맵 데이터
```

## 5. Engine 요약

`Engine/`은 게임 전반에서 공유하는 엔진 DLL이다.

주요 축:

- 코어: `GameInstance`, `Graphic_Device`, `PipeLine`, `Level_Manager`, `Asset_Manager`
- 오브젝트/컴포넌트: `GameObject`, `Component`, `Layer`, `Level`, `Prototype_Manager`, `Prefab_Manager`
- 렌더링/리소스: `Shader`, `Texture`, `Renderer`, `RenderTarget`, `Model`, `ModelMaterial`, `Model_BinaryLoader`
- 애니메이션: `Animation`, `Animation_Manager`, `Bone`, `Channel`
- 애니메이션 노티파이: `AnimNotify`, `AnimNotifyState`, `AnimNotify_Factory`, `AnimNotify_Serializer`
- UI: `UIObject`, `HUD`, `Panel`, `UI_Manager`, `UI_Text`, `Text_Renderer`, `UI_AnimPlayer`
- BT/AI: `BehaviorTree`, `Blackboard`, `BTNode`, `BTTask`, `BTDecorator`
- 카메라/시네마틱: `Camera`, `Camera_Manager`, `Camera_Cinematic`, `CameraTrack_Player`, `CameraTrack_Serializer`
- 충돌: `Bounding_*`, `Collider`, `Collision_Manager`, `CollisionProxy_Manager`, `Collision_Define`
- 이펙트: `EffectComponent`, `EffectMeshObject`, `EffectBilldboardObject`, `Particle_Point`, `VIBuffer_Trail`
- 물리/타겟팅/그림자: `PhysXMgr`, `Target_Manager`, `Shadow`

엔진을 수정할 때 자주 보는 위치:

```text

Engine/Private/
Engine/Public/Engine_*.h
Engine/Public/Model*.h
Engine/Public/AnimNotify*.h
Engine/Public/Collision*.h
Engine/Public/Effect*.h
```

## 6. Client 요약

`Client/`는 실제 게임 플레이 로직 DLL이다. 현재 프로젝트에서 가장 많이 확장된 영역이다.

주요 축:

- 플레이어: `Player`, `MyPlayer`, `RemotePlayer`, `PreviewPlayer`
- 상태 머신: `PlayerState_*`
- 전투/스킬: `Skill_*`, `SkillObject_*`, `SkillComponent`, `ComboProfile_Manager`
- 보스/몬스터: `Boss_Pain`, `Monster_Leaf`, `Monster_Wood`, `EnemyCharacter`
- 전투 BT: `BTTask_Attack`, `BTTask_PainForceSkill`, `BTTask_UpdateBossContext` 등
- 이펙트/트레일: `AttachedEffectObject`, `StretchingMeshEffect`, `WireMeshEffect`, `Trail_Component`, `SwordTrail_Component`, `GhostEffect_Component`
- 애니메이션 노티파이: `AN_*`, `ANS_*`
- UI: `UI_PlayerHUD`, `UI_BossHp`, `UI_MissionMarker`, `UI_Timer`, `UI_WireLockOn`
- 레벨: `Level_MainTitle`, `Level_Loading`, `Level_Gameplay`, `Level_CharacterSetup`, `Level_Lobby`, `Level_Konoha`
- 네트워크: `NetworkManager`, `ServerSession`, `Client_PacketHandler`, `Replicator`
- 로딩/데이터: `Loader`, `ResourceLoader`, `SkillDataManager`

클라이언트 작업 때 자주 보는 위치:

## 7. Editor 요약

`Editor/`는 ImGui 기반 에디터다. 단순 씬 편집기를 넘어 애니메이션, 시네마틱, UI 애니메이션, 이펙트, 인스펙터 확장까지 담당한다.

주요 축:

- 코어: `Editor_MainApp`, `Editor_Manager`, `EditorInstance`, `ImGui_Manager`
- 뷰: `Scene_View`, `Game_View`, `Hierarchy`, `Inspector`, `Content_Browser`, `Console_View`
- 전문 뷰: `BehaviorTree_View`, `Prefab_View`, `Profiler_View`, `Animation_View`, `UI_Animation_View`, `Cinematic_View`, `Effect_View`
- 인스펙터: `Transform_Inspector`, `CombatStat_Inspector`, `Collider_Inspector`, `Skill_Inspector`, `Effect_Inspector`
- 시퀀서: `AnimSequencerAdapter`, `CameraSequencerAdapter`, `UI_AnimSequencerAdapter`
- Undo/Redo: `CommandHistory`, `Action_Command`, `Property_Command`

에디터 작업 때 자주 보는 위치:

```text

Editor/Private/
```

- `Converter` 계열: 변환 중심 로직
- `BinaryWriter`: 바이너리 출력 보조

## 15. 현재 구조 판단 메모

- 프로젝트 중심은 `Engine + Client + Editor + Resources` 조합이다.
- `Client`는 전투, 스킬, 보스, UI, 이펙트, 레벨이 계속 확장되는 메인 작업 영역이다.
- `Engine`은 렌더링, 충돌, 애니메이션, 이펙트, UI, BT, 카메라 같은 공용 기반을 담당한다.
- `Editor`는 단순 뷰어가 아니라 실제 리소스/시퀀스/이펙트 편집 도구로 보는 편이 맞다.
- `Client/Bin/Resources/Data/json`은 코드만큼 중요한 런타임 데이터 원본이다.
- `PROJECT_STRUCTURE.md`는 보존 문서로 유지하고, 빠른 현재 요약은 이 `구조/프로젝트_구조_요약.md`를 먼저 보면 된다.
