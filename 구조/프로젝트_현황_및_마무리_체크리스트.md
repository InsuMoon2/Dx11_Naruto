## 1. 프로젝트 요약

`Dx11_Naruto`는 DirectX 11 기반 자체 엔진 위에서 만든 나루토 소재 3D 액션 게임이다. 엔진, 클라이언트, ImGui 에디터, IOCP 서버, Assimp 변환 툴까지 자체 구축한 풀스택 개인/소규모 프로젝트다. 구조 자체는 [프로젝트_구조_요약.md](이하 참조)에 이미 상세히 정리되어 있으므로, 이 문서는 **"지금 상태"와 "마무리해야 할 것"**에 집중한다.

## 3. 구현된 주요 기능 (요약)

기존 [구조/프로젝트_구조_요약.md](프로젝트_구조_요약.md)에 상세 목록이 있으니 여기선 굵직한 것만:

- **렌더링/애니메이션**: 디퍼드 셰이더, 스켈레탈 애니메이션, 애니메이션 노티파이(Notify/NotifyState) 시스템, 카메라 시네마틱 시퀀서
- **전투**: 플레이어 상태머신, 스킬 시스템(콤보 프로필 포함), 보스(Pain) AI, 이펙트/트레일(소드 트레일, 나선수리검 등), 벽 충돌 + PhysX 기반 충돌 처리(현재 브랜치 `feat/colliison-physx-quard-tree`)
- **UI**: HUD, 보스 HP바, UI 애니메이션 시스템(트랙/키프레임 + 시퀀서)
- **네트워크**: Protobuf 기반 IOCP 서버(ServerCore + GameServer), 로비/채팅, 동기화, 트리거 시스템
- **에디터**: Scene/Game View, Hierarchy, Inspector, Behavior Tree View, Prefab View, Animation/Cinematic/Effect View, Undo/Redo(CommandHistory)
- **툴체인**: AssimpTool(FBX→커스텀 바이너리 변환), MapTools 파이프라인, XLSX→JSON 데이터 테이블 변환

즉 **엔진+에디터+서버+게임 로직이 실제로 맞물려 도는 상태까지는 도달**했고, 한 번 패키징된 데모 빌드도 존재한다.
